📊 DATABASE SCHEMA (Prisma ORM)
═══════════════════════════════════════════════════════════════════════════════

✅ User Table
   ├─ id (primary key)
   ├─ email (unique)
   ├─ password (hashed)
   ├─ name
   ├─ role (admin/manager/staff)
   └─ timestamps

✅ Product Table
   ├─ id (primary key)
   ├─ name (unique)
   ├─ description
   ├─ price (selling price)
   ├─ cost (cost price)
   ├─ category
   ├─ image URL
   ├─ Relationship: One-to-One with Inventory
   └─ Relationship: One-to-Many with BillItem

✅ Inventory Table
   ├─ id (primary key)
   ├─ productId (foreign key, unique)
   ├─ quantity
   ├─ minLevel
   ├─ maxLevel
   └─ timestamps

✅ Bill Table
   ├─ id (primary key)
   ├─ billNo (unique auto-generated)
   ├─ totalAmount
   ├─ discount
   ├─ tax
   ├─ finalAmount
   ├─ paymentMethod (cash/card/upi)
   ├─ status
   ├─ notes
   ├─ timestamps
   └─ Relationship: One-to-Many with BillItem

✅ BillItem Table
   ├─ id (primary key)
   ├─ billId (foreign key)
   ├─ productId (foreign key)
   ├─ quantity
   ├─ price (at time of sale)
   ├─ total (quantity × price)
   └─ timestamp

✅ DailySummary Table
   ├─ id (primary key)
   ├─ date (unique)
   ├─ totalSales
   ├─ totalBills
   ├─ totalProfit
   └─ timestamps

🔐 API ENDPOINTS (40+ endpoints)
═══════════════════════════════════════════════════════════════════════════════

Authentication (/api/auth/)
   POST   /register          → Register new user
   POST   /login             → User login (returns JWT)
   GET    /profile           → Get user profile (auth required)

Products (/api/products/)
   GET    /                  → List all products
   POST   /                  → Create product
   GET    /:id               → Get product details
   PUT    /:id               → Update product
   DELETE /:id               → Delete product

Inventory (/api/inventory/)
   GET    /                  → List all inventory
   GET    /:productId        → Get inventory item
   POST   /:productId/update → Update quantity
   PUT    /:productId/levels → Set min/max levels
   GET    /alerts/low-stock  → Get low stock items

Bills (/api/bills/)
   POST   /                  → Create bill
   GET    /                  → List bills
   GET    /:id               → Get bill details
   PUT    /:id/status        → Update bill status
   DELETE /:id               → Delete bill

Dashboard (/api/dashboard/)
   GET    /sales-summary     → Sales summary (configurable days)
   GET    /todays-summary    → Today's sales data
   GET    /product-analytics → Product performance
   GET    /payment-stats     → Payment method breakdown

Health Check
   GET    /api/health        → API status check
